ZIP بیرونی قابل نصب نیست. فقط روی دستگاه خودت باز کن. ابتدا SHA256SUMS.txt را بررسی کن.
ابتدا روی کپی مستقلِ Baci Site V1.15 امتحان کن. این بسته روی سایت یا VPS اصلی اجرا نشده است.

  baci-plugin-manager-update-v0.1.29.zip  ← ارتقای پنل موجود در File Manager
  baci-plugin-manager-v0.1.29.zip         ← جایگزین بستهٔ قبلی برای نصب اول، نه افزونه
  school-classroom-plugin-v0.4.23.zip   ← ZIP افزونه، بدون بازکردن در تب افزونه‌ها
  baci-classroom-recorder-v0.4.23.zip    ← فقط برای VPS ضبط Linux x86-64، شامل گیرندهٔ بومی و سرویس ساخت
  upgrade-v0.4.23.py                    ← ارتقای Recorder نصب‌شدهٔ فعالِ استاندارد 0.4.21 یا 0.4.22
  classroom-board-network.fa.md         ← راهنمای تخته و UDP
  vps-classroom-report.py                ← تشخیص خواندنی UDP/کرنل؛ تنظیمات را تغییر نمی‌دهد

۱) بازهٔ نگهداری بدون زنگ جدید و پس از پایان ساخت/ارسال و ثبت رسید انتخاب کن. از سایت، پایگاه و پوشهٔ خصوصی افزونه‌ها بکاپ بگیر.
۲) در File Manager، برای مدیر استاندارد 0.1.22 تا 0.1.28 با تب افزونهٔ سالم، فقط plugins/school-plugins.php از ZIP مدیر را جایگزین کن. برای نصب قدیمی‌تر یا ترمیم صفحهٔ پنج‌تبی، هر ۱۰ فایل پنل را با مسیرشان جایگزین کن.
۳) بعد از نمایش 0.1.29، روی «آماده‌سازی ارتقا (حفظ داده و کنترل صف)» بزن. اگر مسدود شد، زنگ یا کار ضبط را به پایان عادی برسان؛ «حذف کامل» نزن. ZIP کلاس را بدون بازکردن آپلود و با تنظیمات قبلی فعال کن. تا انتهای نگهداری زنگ جدید باز نکن.
۴) اگر از Recorder استفاده می‌کنی، اسکریپت و ZIP مخصوص را به پوشهٔ خصوصی VPS ببر و همان هش معتبر انتشار را قبل از sudo بررسی کن:

   sudo python3 -I ./upgrade-v0.4.23.py --check-only ./baci-classroom-recorder-v0.4.23.zip
   sudo python3 -I ./upgrade-v0.4.23.py --apply ./baci-classroom-recorder-v0.4.23.zip

   فقط اگر آزمون خط اول موفق است خط دوم را اجرا کن. اسکریپت LiveKit، Caddy، فایروال، مرورگر، کلید و داده‌ها را عوض نمی‌کند.
   برای دریافت از کامیت ثابت، راهنمای docs/vps-recorder-v0.4.23.fa.md در مخزن را ببین. برای نصب اول VPS، README-fa.md داخل ZIP Recorder را بخوان.
۵) «آماده» در صفحهٔ گروه‌ها و شروع موفق هر دو سرویس را ببین. پیش از استفادهٔ مدرسه، با حساب‌ها، PDF و گروه جداگانهٔ تست، یک زنگ را امتحان کن. عدد ظرفیت یا سهم UDP روی VPS واقعی تأیید نشده است.

حین کلاس: حداکثر سه ثبت بومی مستقل، بدون ساخت MP4. ساخت و شروع ارسال تنها با رضایت و از ۱۸۰ دقیقه پس از پایان واقعی (پیش‌فرض قابل تغییر)، وقتی کلاسی باز نیست. کارهای قبلی، کلیدها، گروه‌ها، ساعت و گزارش‌های حضور حفظ می‌شوند؛ اسکریپت روی صف فعال اجرا نمی‌شود. برای هر کلاس حالت عادی، دوربین دبیر + اشتراک مجاز یا فقط صدا + تخته قابل انتخاب است. نوشته، واگرد، بازانجام، صفحه و زوم وابسته به Lossy نیستند؛ تنها لیزر/اشاره‌گر از مسیر سریع Lossy استفاده می‌کنند.
