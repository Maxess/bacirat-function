# نصب تازهٔ Baci VPS ۱٫۳٫۵ — کلاس زنده، ضبط و ارسال فیلم

**مسیر پیشنهادی: Ubuntu 24.04 LTS amd64 تازه، ۱ GiB RAM یا بیشتر، یک فرمان نصب.** ضبط در حالت پیش‌فرض نصب می‌شود. اصلاح تیک‌تیک وسط صحبت در فیلم و اصلاح ۴۰۳ شناخته‌شدهٔ Recorder داخل خود بسته‌اند؛ فایل پایتون یا اجرای وصلهٔ r2 جداگانه لازم نیست. این نسخه **ارتقای درجا برای VPS دارای ضبط نیست** و فیلم‌های قبلی را تغییر نمی‌دهد. VPS فعلی و داده‌های مدرسه را برای نصب تازه ریست یا پاک نکن.

## ۱. آماده‌سازی

- VPS اختصاصی با تصویر رسمی **Ubuntu 24.04 LTS amd64 / x86_64**، systemd، cgroup v2، دسترسی SSH و `sudo`، IPv4 عمومی قابل‌دسترسی و حداقل **۸ GiB فضای خالی** پس از اختصاص swap. برای ضبط‌های بلند فضای بیشتری لازم است. سایت PHP/MySQL مدرسه روی هاست خودش می‌ماند.
- برای نام رسانه، مانند `class.example.ir`، **یک رکورد A مستقیم** به IPv4 VPS بگذار. برای آن نام proxy/CDN یا AAAA نگذار. نشانی HTTPS خود مدرسه متفاوت است؛ زیرپوشهٔ واقعی مثل `/baci` را در نشانی مدرسه بنویس.
- در فایروال ارائه‌دهنده و VPS، **`443/TCP`** برای HTTPS، **`7882/UDP`** برای رسانه و **`7881/TCP`** برای مسیر جایگزین رسانه قابل‌دسترسی باشند. پورت ۸۰ لازم نیست؛ `7880` و `7883` خصوصی بمانند. نصب‌گر فایروال و DNS را تغییر نمی‌دهد.

از [انتشار ۱٫۳٫۵](https://github.com/Maxess/bacirat-function/releases/tag/vps-offline-v1.3.5) این فایل‌ها را بگیر: [آرشیو نصب](https://github.com/Maxess/bacirat-function/releases/download/vps-offline-v1.3.5/baci-classroom-vps-offline-v1.3.5-ubuntu24.04-amd64.tar.gz)، [اسکریپت نصب](https://github.com/Maxess/bacirat-function/releases/download/vps-offline-v1.3.5/install-vps.sh) و [فایل هش‌ها](https://github.com/Maxess/bacirat-function/releases/download/vps-offline-v1.3.5/baci-classroom-vps-offline-v1.3.5-ubuntu24.04-amd64-SHA256SUMS.txt). فایل‌های `ubuntu-source` برای نصب لازم نیستند. [ZIP همراه سایت ۰٫۴٫۲۹](https://github.com/Maxess/bacirat-function/releases/download/vps-offline-v1.3.5/baci-classroom-site-upgrade-v0.4.29.zip) را هم بگیر؛ داخل آرشیو نصب هم هست.

## ۲. نصب مستقیم از انتشار روی VPS تازه

اگر VPS به GitHub و میزبان فایل انتشار دسترسی دارد، در نشست SSH خودت اجرا کن؛ اسکریپت پس از تطبیق هش اجرا می‌شود و خودش هش آرشیو را جداگانه بررسی می‌کند:

```bash
work=$(mktemp -d) && cd "$work" &&
  curl --disable -fsSL --proto '=https' --proto-redir '=https' --tlsv1.2 \
    --connect-timeout 12 --max-time 30 https://github.com/Maxess/bacirat-function/releases/download/vps-offline-v1.3.5/install-vps.sh -o install-vps.sh &&
  printf '%s  %s\n' 'bd60e313e08b831b2965073800e2df5b2c480ecf1208559235cf53e48f5c7f4a' install-vps.sh | sha256sum --strict --check &&
  bash ./install-vps.sh
```

اگر ابتدا پیش‌بررسی بدون نصب می‌خواهی، خط آخر را به `bash ./install-vps.sh --check` تغییر بده. برای TLS با PEM یا آرشیو محلی، پوشهٔ دارای همان فایل‌ها را طبق بخش بعد استفاده کن.

### مسیر فایل محلی برای دسترسی ضعیف به GitHub

اگر VPS به GitHub دسترسی مطمئن ندارد، آرشیو و اسکریپت را **کنار هم** در یک پوشهٔ تازه با SFTP منتقل کن؛ در اتصال اول اثر انگشت SSH را با پنل ارائه‌دهنده تطبیق بده. قبل از اجرا هش هر فایل دانلودشده را با انتشار مقایسه کن. برای نمونه، اگر بسته‌ها و فایل هش‌ها را به `~/baci-vps-135` منتقل کرده‌ای، در نشست SSH همان پوشه را باز کن (اگر نام پوشه متفاوت است، مسیر واقعی را وارد کن):

```bash
cd ~/baci-vps-135
ls -l -- install-vps.sh baci-classroom-vps-offline-v1.3.5-ubuntu24.04-amd64.tar.gz baci-classroom-vps-offline-v1.3.5-ubuntu24.04-amd64-SHA256SUMS.txt
sha256sum --strict --check --ignore-missing baci-classroom-vps-offline-v1.3.5-ubuntu24.04-amd64-SHA256SUMS.txt
```

اگر `ls` فایل را پیدا نکرد، مسیر یا انتقال فایل را بررسی کن و ادامه نده. برای اسکریپت و آرشیو هر دو باید `OK` ببینی. در PowerShell می‌توانی از `Get-FileHash -Algorithm SHA256` استفاده کنی. سپس در همان پوشه:

```bash
bash ./install-vps.sh
```

سه پاسخ را بده: **نشانی HTTPS سایت مدرسه** (با زیرپوشه اگر دارد)، **نام رسانه** (بدون `https://` یا پورت)، و **IPv4 VPS**. می‌توانی با `--site`، `--media` و `--ipv4` هم بدهی. خود نصب‌گر هش آرشیو، شرایط سیستم و طرح APT را بررسی می‌کند و وابستگی‌ها را از خود بسته نصب می‌کند. `--check` اختیاری است: نصب نمی‌کند، گواهی سفارش نمی‌دهد و بازبودن پورت از بیرون را هم ثابت نمی‌کند. در آن حالت `apt_plan=ok` و `preflight=ok` را ببین.

- **دانلود مستقیم اختیاری:** اگر VPS به انتشار دسترسی دارد، فقط اسکریپت بررسی‌شده را منتقل کن؛ وقتی آرشیو محلی نیست، همان نسخه را از GitHub می‌گیرد. `--bundle /path/to/archive.tar.gz` برای فایل محلی و `--mirror 'https://…/نام‌آرشیو.tar.gz'` برای کپیِ یکسان روی آینه‌اند. هش ثابت در همهٔ مسیرها لازم است. اگر فقط آرشیو تأییدشده را داری، پس از استخراج `sudo bash baci-classroom-vps-offline/install.sh` هم بدون اسکریپت بیرونی کار می‌کند.
- **HTTPS:** بدون PEM، Caddy از Let’s Encrypt با TLS-ALPN-01 روی `443/TCP` گواهی می‌گیرد و تمدید می‌کند. ساعت درست، DNS عمومی، ورودی ۴۴۳ و دسترسی خروجی به مرجع صدور لازم‌اند. اگر این مسیر ممکن نیست، گواهی عمومی **همان نام رسانه** با زنجیرهٔ کامل `fullchain.pem` و کلید بدون عبارت رمز `privkey.pem` را کنار آرشیو بگذار (`chmod 600 privkey.pem`). هر دو باید فایل عادی باشند، نه symlink. `--tls files --cert ./chain.pem --key ./key.pem` هم معتبر است. در این حالت نصب به ACME نیاز ندارد و تمدید دستی/با صادرکننده است. گواهی نامعتبر، TLS ناامن یا غیرفعال‌کردن فایروال راه‌حل نیست.
- **حافظه:** `compact` حداقل ۴۴۸ MiB RAM قابل‌مشاهده می‌خواهد و زیر ۸۹۶ MiB به `SwapTotal >= 512000 kB` نیاز دارد؛ `full` از ۱۷۹۲ MiB قابل‌مشاهده انتخاب می‌شود. اگر پلن ۵۱۲ MiB داری، از swap فعالِ ارائه‌دهنده استفاده کن یا ابزار اختیاری و بررسی‌شدهٔ `baci-prepare-swap.sh` را با `--check` بررسی و فقط با `--apply` تأیید کن. نصب‌گر خودسرانه swap یا سیاست هسته را عوض نمی‌کند. `--profile live` فقط انتخاب عمدی برای **بدون ضبط** است، نه راه رفع کمبود حافظه برای ضبط.

موفقیت محلی برای حالت ضبط: `installation=ok … renderer_mp4=ok school_pairing=required`. این یعنی نرم‌افزار نصب شده، HTTPS و ساخت MP4 آزمایش شده‌اند و **هنوز باید مدرسه را وصل کنی**. نصب‌کننده مسیر فایل خصوصی اتصال را چاپ می‌کند.

## ۳. مدرسه و گروه را وصل کن و یک زنگ واقعیِ آزمایشی بگیر

1. ZIP همراه سایت را روی رایانه باز کن و برای نصب **مدیر افزونه‌ها ۰٫۱٫۳۶ و کلاس مجازی ۰٫۴٫۲۹** مراحل «START-HERE-fa.txt» را دنبال کن. برای سایت موجود، بکاپ بگیر و فقط بعد از اتمام کلاس‌ها و خالی شدن صف ضبط و اعلان «آماده‌سازی ارتقا (حفظ داده و کنترل صف)» را بزن. سپس به «تنظیمات دیگر ← افزونه‌ها ← کلاس مجازی ← اتصال یک‌مرحله‌ای VPS جدید» برو. فایل `Baci-VPS-pairing.json` را **فقط در فرم HTTPS مدیر کل همان مدرسه** وارد کن و کلاس و ضبط را فعال کن. اگر فایل صادر نشده، با حساب SSH خودت `sudo baci-vps export` را بزن؛ فایل موجود بازنویسی نمی‌شود. فایل اتصال، کلید PEM و توکن ربات را در چت، وب‌ریشه یا گزارش خطا نگذار.
2. Cron ‏**CLI روی هاست مدرسه** هر دقیقه برقرار باشد. نمونه برای زیرمسیر `/baci`: `/usr/bin/php /home/CPUSER/public_html/baci/plugins/school-plugins.php classroom-job /baci`. مسیرها را با مقدار واقعی عوض کن؛ برای سایت ریشه‌نشین آرگومان آخر را حذف کن. اگر سایت سالم است آن را از نو نصب نکن. برای هاست خالی، فقط بخش‌های مربوط به سایت و Cron در [راهنمای سایت پایه](https://github.com/Maxess/bacirat-function/blob/bd832cb6ea00dbf123985b1023273046c8999133/server/offline/README-fa.md) را دنبال کن، نه دستور VPS قدیمی آن را.
3. ربات **بله یا روبیکا** را در سایت و گروه آزمایشی ثبت کن، اجازهٔ ارسال ویدیو بده و در «گروه‌های پیام‌رسان و ضبط کلاس» همان گروه را به کلاس پیوند بده. سایت و VPS باید به API پیام‌رسان برسند. روبیکا برای آپلود از میزبان فایل هم استفاده می‌کند.
4. `sudo baci-vps doctor --online --wait` را روی VPS بزن. `school_webhook=ok` و `school_recorder=ready` را ببین. این بررسی فقط‌خواندنی است؛ وقتی مدرسه هنوز heartbeat معتبر همان Recorder را ندارد، خروجی موفق نمی‌دهد. `/healthz` از یک شبکهٔ دیگر باید HTTPS معتبر نشان بدهد؛ به‌تنهایی پخش یا تحویل فیلم را ثابت نمی‌کند.
5. با دبیر و دانش‌آموز در **دو دستگاه و ترجیحاً دو شبکه** یک زنگ عادی آزمایشی بگیر. صدا، تصویر و اشتراک صفحه را بررسی کن؛ با اطلاع و رضایت افراد ضبط را شروع کن. وسط چند جملهٔ پیوسته، ارائه‌دهنده روی «نمایش در ضبط» بالای یک وب‌کم روشن بزند. دوباره همان دکمه را بزند تا چیدمان قبلی برگردد. دبیر «بستن کلاس برای همه» و سپس تأیید ارسال را انتخاب کند. پس از تأخیر تنظیم‌شدهٔ مدرسه (پیش‌فرض **۱۸۰ دقیقه**؛ برای تمرین می‌توان کوتاه‌تر تنظیم کرد) و در نبود زنگ باز، دریافت و **پخش MP4 در همان گروه** را ببین: صدای وسط صحبت، قاب بزرگ وب‌کم به جای تخته (بدون حذف صفحهٔ دارای اولویت)، برگشت تخته در صورت انتخاب قبلی و عبارت دقیق «طراحی و توسعه : سید مهدی بیات» بالای فیلم. یک زنگ جدا هم با «نفرست» ببند و نبود ارسال را تأیید کن.

## اتصال ضعیف یا مرورگر قدیمی

پس از نصب ZIP تازه روی **سایت مدرسه**، «نمای سبک درس» در صفحهٔ انتظار در دسترس است. بعد از ورود به حساب مدرسه، تا زمانی که مسئول مجاز در زنگ حضور تأییدشده دارد، می‌توان پیام‌های تازه و تختهٔ سبک را دستی تازه کرد و فایل جاری را به‌دلخواه گرفت. این نما صدا و ثبت حضور ندارد. دریافت فقط صدا به مسیر WebRTC نیاز دارد؛ اگر فقط ۴۴۳ از شبکهٔ کاربر عبور کند، این بسته مسیر TURN روی ۴۴۳ ندارد. از همان دستگاه و شبکه، قبل از اولین زنگ هر دو نما را بررسی کن.

## اگر پیش‌بررسی یا اتصال رد شد

| نشانه | کار بعدی |
|---|---|
| دانلود یا SHA-256 ناموفق | همان آرشیو را دوباره بگیر یا با SFTP منتقل کن. از آرشیو با هش نامطابق استفاده نکن. |
| `apt_plan=blocked` / حذف بسته لازم است | حذف اجباری یا downgrade نکن. ۱٫۳٫۵ اصلاح سازگاری Noble GA را دارد؛ ۱٫۳٫۰ را دوباره امتحان نکن. فقط سطرهای تعارض بدون کلید را گزارش کن. [جزئیات APT](https://github.com/Maxess/bacirat-function/blob/a93202389d472d4ef4a21dfed43f80cb1899bb86/docs/vps-noble-dependencies.fa.md) |
| DNS، TLS، پورت یا مسیر رسانه | رکورد A، ساعت، زنجیرهٔ معتبر، ورودی‌های فایروال پنل/VPS و شبکهٔ کاربران را بررسی کن. TCP رسانه جای ۴۴۳ نیست. |
| `reason=http_403` | فعال‌بودن ضبط، اتصال همان مدرسه و قانون میزبانی مسیر احرازشدهٔ ضبط را بررسی کن. مشکل هویت HTTP شناخته‌شده در ۱٫۳٫۵ رفع شده؛ هر ۴۰۳ همین علت را ندارد. |
| `reason=local_pairing_mismatch`، `paired_waiting_for_heartbeat` یا `another_worker` | فقط وضعیت و لاگ مختصر بدون کلید را بررسی کن؛ جفت‌سازی، صف یا فایل‌های ضبط قبلی را پاک نکن. |
| کلاس وصل است ولی فیلم نرسید | پس از heartbeat، مقصد و اجازهٔ ربات، تأیید بستن عادی، تأخیر/نبود زنگ باز و دسترسی API/آپلود را به‌ترتیب بررسی کن. |

**نصب زندهٔ موجود:** `--add-recorder --check` و سپس `--add-recorder` فقط برای نصب‌های مدیریت‌شدهٔ سالم **`live`** (از ۱٫۲٫۰، ۱٫۳٫۰ تا ۱٫۳٫۴ یا همین نسخه)، پس از پشتیبان، بستن همهٔ کلاس‌ها و تخلیهٔ صف است. جفت‌سازی و HTTPS موجود را نگه می‌دارد؛ دامنه، IP یا PEM جدید نده. اگر نصب موجود ضبط دارد، مسیر نصب تازه را برای ارتقای آن اجرا نکن.

**حد آزمون:** پیوند اجرای آزمون‌های همان آرشیو و مسیر دریافت عمومی در صفحهٔ انتشار آمده است. گیرنده‌های بله و روبیکا و مرجع ACME در آزمون ایزوله شبیه‌سازی شده‌اند؛ دسترسی و پخش در گروه واقعی، ارائه‌دهندهٔ VPS و شبکهٔ واقعی مدرسه باید با مراحل بالا تأیید شوند.
