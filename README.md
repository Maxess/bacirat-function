# bacirat-function

پلتفرم کلاس مجازی سفارشی‌سازی‌شده بر پایهٔ **Galene** (سیستم ویدئوکنفرانس
متن‌باز) — برای نصب و اجرا روی سرور لینوکس.

## ساختار ریپو

| مسیر | توضیح |
|------|-------|
| `galene/` | سورس‌کد کامل Galene (نسخهٔ اصلی از [jech/galene](https://github.com/jech/galene)) — نقطهٔ شروع سفارشی‌سازی‌ها |
| `persianmeet/` | نسخهٔ قدیمی (باینری آمادهٔ PersianMeet) — فقط برای مرجع نگه داشته شده است |

## نصب روی سرور (از روی همین ریپو)

پیش‌نیاز: Go نسخهٔ 1.24 یا بالاتر روی سرور (فقط برای بیلد؛ سرور نهایی فقط
یک باینری سبک اجرا می‌کند).

```sh
git clone https://github.com/Maxess/bacirat-function.git
cd bacirat-function/galene

# بیلد باینری (بدون وابستگی به C — سبک و قابل اجرا روی ضعیف‌ترین سرورها)
CGO_ENABLED=0 go build -ldflags='-s -w'

# ساخت گروه/کلاس نمونه
mkdir -p groups data
echo '{"users": {"admin": {"password": "CHANGE_ME", "permissions": "op"}}}' > groups/my-class.json

# اجرا
./galene
```

سپس در مرورگر: `https://localhost:8443/group/my-class/`

راهنمای کامل نصب و استقرار (systemd، گواهی TLS و…) در فایل
[`galene/galene-install.md`](galene/galene-install.md) موجود است.

## همگام‌سازی با نسخهٔ اصلی (Upstream)

سورس داخل `galene/` از این ریپو گرفته شده است:

- Upstream: https://github.com/jech/galene
- وب‌سایت رسمی: https://galene.org
- لایسنس: MIT (فایل `galene/LICENCE`) — آزاد برای استفاده و تغییر

برای دریافت آپدیت‌های بالادست، کافی است نسخهٔ جدید را از بالادست بگیرید و
فایل‌های تغییرکرده را روی `galene/` اعمال کنید (تغییرات سفارشی ما در
فایل‌های جداگانه/ماژول‌های جدید نگه داشته می‌شوند تا این کار آسان بماند).

## تغییرات سفارشی برنامه‌ریزی‌شده

همهٔ تغییرات با هدف **حداقل مصرف منابع** (اجرا روی ضعیف‌ترین سرورها)
انجام می‌شوند:

1. **دسترسی‌های دبیر (Teacher)** در کلاس — نقش‌ها و مجوزهای تفکیک‌شده
2. **پنل مدیریت سیستم** — مدیریت کاربران، کلاس‌ها و تنظیمات
3. **تختهٔ سفید سبک و بهینه** برای کلاس (همگام‌سازی با حداقل ترافیک)
4. **سیستم حضور و غیاب** دانش‌آموزان
5. **اتصال API به وب‌سایت** برای دریافت کلاس‌ها و دانش‌آموزان
6. **برندینگ و سفارشی‌سازی ظاهری** از داخل پنل مدیریت
