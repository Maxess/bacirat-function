# bacirat-function — PersianMeet (لیون‌آموزش / learn100) روی سرور لینوکس شما

این ریپوی **شما**ست و شامل همه چیزی است که برای **خرید/دریافت، نصب، پیکربندی، نگهداری و یکپارچه‌سازی**
نرم‌افزار بستر کلاس مجازی **PersianMeet** (همان محصول learn100.ir) روی **سرور لینوکس خودتان** لازم دارید:

- 📄 **بایگانی کامل مستندات رسمی** (نصب محلی، دیپلوی لینوکس/ویندوز، API، config.yml) در [`docs/00-official-docs.md`](docs/00-official-docs.md)
- 🛠️ **اسکریپت نصب خودکار لینوکس** (اوبونتو/دبیان) مطابق مستندات رسمی + systemd + وافزالی + پشتیبانی فایروال — در [`deploy/`](deploy/)
- 🔌 **کلاینت آماده‌ی API رسمی** (پایتون خالص + مثال‌های curl) برای ساخت/مدیریت اتاق‌ها از سایت یا سیستم خودتان — در [`api/`](api/)
- 📚 راهنمای **معماری، دیپلوی، سفارشی‌سازی و عیب‌یابی** — در [`docs/`](docs/)

## ⚠️ قبل از هر چیز (مهم و صادقانه)

**سورس بک‌اند PersianMeet عمومی نیست.** این محصول طبق جدول مقایسه‌ی خودِ سازنده
(`sunmobiir/persianmeet` در گیت‌هاب) «open source: ❌» است و به‌صورت **باینری تک‌فایلی کامپایل‌شده**
(به‌همراه `config.yml` و فایل‌های استاتیک وب) توزیع می‌شود. یعنی:

1. هیچ «سورس بک‌اندی» وجود ندارد که ما بتوانیم به صورت قانونی در این ریپو بیاوریم یا ویرایش کنیم.
   ریورس‌انجینیرینگ/کرک/دی‌کامپایل باینری برای دور زدن لایسنس انجام نمی‌شود.
2. دانلود پکیج رسمی (`persianmeet-linux-v0.26.3.zip`) **از این محیط ابری ممکن نبود** — دسترسی اینترنت
   این محیط فقط به `github.com`، `npmjs.org` و `pypi.org` محدود است. اما **در سرور شما** لینک دانلود
   کاملاً کار می‌کند و اسکریپت نصب این ریپو آن را خودش دانلود می‌کند (یا می‌توانید با `wget` دستی بگیرید).
3. چیزی که در این ریپو قرار داده شده، **ابزاری قانونی و عملی برای میزبانی شخصی و تغییر ظاهر/رفتار**
   در لایه‌هایی است که محصول خودش پشتیبانی می‌کند: `config.yml`، فایل‌های استاتیک `wwwroot`
   (لوگو/رنگ/متن)، دامنه و SSL، فایروال، سرویس systemd، بکاپ/آپدیت، و **API رسمی** برای اتصال به سایت شما.
4. اگر واقعاً به تغییر «منطق داخلی» (مثلاً پروتکل اتاق یا رفتار سمت سرور) نیاز دارید، باید از خودِ
   فروشنده لایسنس سورس/تجاری بگیرید. اگر دنبال یک بستر کلاس مجازی **کاملاً متن‌باز با سورس کامل**
   هستید، به انتهای [`docs/02-customization.md`](docs/02-customization.md) نگاه کنید.

جزئیات کامل: [`NOTICE.md`](NOTICE.md) — [`docs/02-customization.md`](docs/02-customization.md)

## پیش‌نیازها (مطابق مستندات رسمی)

| مورد | مقدار |
|---|---|
| سیستم‌عامل پشتیبانی‌شده | Ubuntu / Debian تمیز (بدون وب‌سرور اشغال‌کننده‌ی ۸۰/۴۴۳) |
| دسترسی | کاربر root یا sudo |
| RAM / CPU | حداقل ۲ گیگ رم و ۲ هسته (نسخه‌ی Windows سازنده ۳ گیگ می‌خواهد) |
| شبکه | IP عمومی + یک **دامنه یا زیردامنه** که به آن IP اشاره کند (برای SSL رایگان Let's Encrypt لازم است) |
| وابستگی‌ها | `wget nano unzip mupdf-tools` (اسکریپت نصب همه را می‌گیرد) |

## شروع سریع (روی سرور شما)

```bash
git clone <آدرس همین ریپو در گیت‌هاب شما>
cd bacirat-function
sudo DOMAIN=class.example.com ./deploy/install.sh
```

بعد از نصب:

1. در DNS، یک رکورد A برای `class.example.com` به IP سرور بزنید (قبل از روشن کردن `auto_ssl`).
2. مرورگر را باز کنید: `https://class.example.com`
3. ورود اولیه: کاربر `admin` و رمز `1111` — **فوراً از پنل مدیریت رمز را عوض کنید.**
4. برای ساخت اتاق از طریق API:

```bash
python3 api/persianmeet_api.py --base-url https://class.example.com create \
    --title "کلاس من" --user-count 100
```

## خواسته‌های شما کجاست؟

بعد از نصب، هر تغییری که بخواهید روی این بستر انجام دهید در یکی از این لایه‌هاست:

| لایه | ابزار | فایل راهنما |
|---|---|---|
| ظاهر و برندینگ (لوگو/رنگ/متن) | فایل‌های `wwwroot` داخل پکیج + `config.yml` | `docs/02-customization.md` §2 |
| دامنه، SSL، پورت | `config.yml` (`auto_ssl`) یا nginx جلوی آن | `docs/02-customization.md` §1, و `deploy/nginx.reverse-proxy.conf` |

| نگهداری سرور (service, بکاپ, لاگ) | `deploy/` | `docs/03-deployment-guide.md` |

اگر سورس را در `persianmeet-src/` این ماشین یا ریپوی خصوصی جدا بگذارید، آن‌ها را هم پیاده می‌کنیم.
