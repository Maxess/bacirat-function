# bacirat-function

## کلاس مجازی برای سایت آزمایشی Baci

مبنا [شاخهٔ `arena/dbe3eaf3-baci`](https://github.com/mtagbot/Baci/tree/arena%2Fdbe3eaf3-baci)، [بستهٔ سایت `Release_V1.15` (نسخهٔ `4.221.0`)](https://github.com/mtagbot/Baci/blob/e0f3f686448642cf04ea01fcb60e79a7a786b902/Release_V1.15-Site.zip) است.

1. [فایل‌های پنل Baci و مدیر ۰٫۱٫۱۰](artifacts/baci-plugin-manager-v0.1.10.zip) — [راهنمای نصب و ارتقا](plugin-manager/README-fa.md)، `UPSTREAM.json` و وصلهٔ مخصوص همین نسخه. بستهٔ قدیمی `mtagbot` را روی Baci جایگزین نکن.
2. [افزونهٔ کلاس مجازی ۰٫۴٫۴](artifacts/school-classroom-plugin-v0.4.4.zip) — ZIP را در **تنظیمات دیگر ← افزونه‌ها** آپلود و فعال کن. برای ارتقا، ابتدا با مدیر قبلی «غیرفعال‌سازی (حفظ داده)» بزن. [چهار ساعت زنگ](plugin-manager/README-fa.md#bell-hours) و گزارش‌های قبلی حفظ می‌شوند.
3. [آزمایش ۲۴ ساعتهٔ جمعه](plugin-manager/README-fa.md#friday-test) — در تنظیمات کلاس مجازی یک جمعهٔ میلادی مشخص را ثبت کن. از نیمه‌شب تا نیمه‌شب تهران، دبیران فعال در هر کلاسِ تعریف‌شدهٔ سال پیش‌فرض یک اتاق آزمایشی مشترک دارند. ایجاد اتاق با نخستین کلیک دبیر است. مدیر می‌تواند **ورود آزمایشی دانش‌آموزانِ همان کلاس** را جداگانه فعال کند تا انتظار و تایمر را امتحان کنند؛ بدون گزارش رسمی یا اعلان. برنامهٔ عادی عوض نمی‌شود و تست به جمعهٔ بعد منتقل نمی‌شود.
4. [وب‌هوک بومی LiveKit در VPS تست](server/WEBHOOK-fa.md) — فقط اگر گیرندهٔ فعلی تنظیم نیست؛ در ارتقا با وب‌هوک سالم، VPS تغییر نمی‌کند. [ادغام دستی پیکربندی سفارشی](server/README-fa.md#manual-native-events).

افزونه از نشست، پایگاه و حساب‌های همان مدرسه استفاده می‌کند. در Baci، جدول برنامهٔ هفتگی مدیریت جمعه را ثبت نمی‌کند؛ حالت آزمایشی مستقل از آن است. برای کلاس‌های رسمی، مجوز دبیر و برنامهٔ هفتگی همچنان ملاک‌اند و انتظار/وقفه در حضور حساب نمی‌شود. اتاق صوتی اکنون چیدمان تیره و واکنش‌گرا با تختهٔ بزرگ، گفت‌وگو و پنل حاضران دارد. حضور با ساعت و دقیقه نمایش داده می‌شود، نام خودت در حاضران برجسته است و پیام‌های تازه بالای گفت‌وگو می‌آیند. نوشته هنگام حرکت قلم همگام می‌شود و پاک‌کن با لمس یا کشیدن روی یک خط، تمام همان حرکت قلم را برمی‌دارد. زمینهٔ تصویر/PDF و نوبت صدا حفظ شده‌اند؛ دوربین و اشتراک صفحه فعال نشده‌اند. نصب را روی کپی مستقل انجام بده؛ هیچ تغییری روی سایت یا VPS اصلی اجرا نشده است.

### ساخت و آزمون محلی

```sh
python3 scripts/build-managed-school.py --output-dir /tmp/school-classroom-build
php tests/plugin-manager.php
php tests/school-classroom.php
php tests/classroom-lessons.php
node --test tests/classroom-*.cjs
MPM_TEST_BACI=/tmp/baci-site python3 -m unittest discover -s tests -p 'test_*.py'
```

ساخت، SDK ثابت از ZIP منتشرشدهٔ قدیمی و PDF.js ثابت از npm را با هش تأیید می‌کند. برای بازسازی [مدیر قدیمی ۰٫۱٫۷ و کلاس ۰٫۴٫۱](https://github.com/Maxess/bacirat-function/tree/c63cefd97defc6f2026a63af5ed5a87fb6a919eb) از سورس همان انتشار استفاده کن. `MPM_TEST_BACI` باید به خروجی بستهٔ دست‌نخوردهٔ Baci Site V1.15 اشاره کند؛ بدون آن آزمون اعمال/برگشت وصلهٔ Baci رد می‌شود (skip). برای ساخت آفلاین از `--pdf-archive` با همان آرشیو npm استفاده کن. آزمون PHP به `pdo_sqlite` و برای چرخهٔ مدیر به `ZipArchive` و `OpenSSL` نیاز دارد. برای اجرای `tests/plugin-manager.php` و `tests/classroom-lessons.php` روی MariaDB/MySQL، `MPM_TEST_DSN` را روی **پایگاه محلی خالی و موقت** `mpm_fixture_*` تنظیم کن (نمونه: `mysql:host=127.0.0.1;port=3306;dbname=mpm_fixture_local;charset=utf8mb4`) و `MPM_TEST_USER` و `MPM_TEST_PASSWORD` را در محیط بده. پایگاه واقعی مدرسه را به آزمون نده.

آزمون‌ها زمان زنگ و جمعه، چت/تخته، حدود مجوزها، ارتقا/حذف و اعلان را با دادهٔ مصنوعی بررسی می‌کنند. در آزمون مرورگر HTTPS/MariaDB روی Baci، ورود دانش‌آموز به آزمایش، توقف و ادامهٔ تایمر با خروج و بازگشت دبیر، دیده‌شدن خط پیش از برداشتن قلم، پاک‌کن خط کامل و حفظ صفحات PDF/تصویر در دسکتاپ و موبایل بررسی شد. رسانه شبیه‌سازی شده بود؛ این آزمون جای تأیید صدا، اتصال گوشی یا ظرفیت روی VPS تست را نمی‌گیرد.
