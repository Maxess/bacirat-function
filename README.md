## پایلوت صوتی سایت مدرسه — نصب و حذف از پنل

1. [مدیر افزونه‌ها ۰٫۱٫۴](artifacts/mtagbot-plugin-manager-v0.1.4.zip) — فایل `plugins/school-plugins.php` داخل ZIP را با همین مسیر روی هاست **تست** بگذار. در نصب قبلی، طبق راهنما ورودی قدیمیِ ریشه را بازنشسته کن و پیوندها را ترمیم کن.
2. [کلاس آنلاین ۰٫۲٫۳](artifacts/school-classroom-plugin-v0.2.3.zip) — ZIP را بدون Extract از **تنظیمات دیگر ← افزونه‌ها** نصب کن. اگر نسخهٔ قبلی نصب است، پیش از آپلود اتاق را ببند و افزونه را غیرفعال کن؛ نسخهٔ جدید با حفظ تنظیمات جایگزین می‌شود و تا فعال‌سازی دوباره غیرفعال می‌ماند.
3. [راهنمای نصب و به‌روزرسانی](plugin-manager/README-fa.md) · [راهنمای LiveKit روی VPS و آزمون صدا](server/README-fa.md)

فقط ورودی مدیر در `plugins/` سایت قرار می‌گیرد. فایل‌های نصب‌شدهٔ هر افزونه در `plugins/<شناسهٔ افزونه>/` داخل فضای خصوصی **خارج از ریشهٔ عمومی وب** نگه‌داری می‌شوند.

پایلوت یک اتاق صوتی با سقف ۴ اتصال است. دبیر یا مدیر مجاز می‌تواند هم‌زمان به چند نفر نوبت میکروفون بدهد و صدا را جداگانه یا برای همه قطع کند. «قطع تصویر» مجوز ترک‌های تصویری همان دانش‌آموز را می‌بندد؛ دوربین و نمایش تصویر در این پایلوت فعال نیستند. از ۰٫۲٫۲ مسیر ارسال صدا از دریافت جداست؛ آزمون پذیرش این است که دانش‌آموز با نوبت معتبر اولین گوینده باشد، بدون اینکه دبیر یا مدیر میکروفونش را روشن کند.

افزونه از نشست مدرسه و MySQL سایت تست استفاده می‌کند. حذف کامل، فایل‌های همهٔ نسخه‌های نصب، جدول اختصاصی و رکورد افزونه را پاک می‌کند و پیوند کلاس را از سه پنل برمی‌دارد؛ مدیر عمومی باقی می‌ماند. ریپوی اصلی `mtagbot`، سایت اصلی و PersianMeet تغییر نکرده‌اند.

### بازسازی و آزمون محلی

```sh
python3 scripts/build-managed-school.py
php tests/plugin-manager.php
php tests/school-classroom.php
node --test tests/classroom-ui.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

اسکریپت ساخت، SDK را از ZIP منتشرشدهٔ قدیمی با SHA-256 ثابت برمی‌دارد و تنها بسته‌ای با manifest مطابق کاتالوگ تولید می‌کند. تست PHP به `ZipArchive`، `OpenSSL` و `pdo_sqlite` نیاز دارد. برای اجرای چرخهٔ مدیریت روی MySQL/MariaDB، یک پایگاه **خالی و موقت** محلی با نام `mpm_fixture_*` بساز و `MPM_TEST_DSN` (به‌شکل `mysql:host=127.0.0.1;port=3306;dbname=mpm_fixture_local;charset=utf8mb4`)، `MPM_TEST_USER` و `MPM_TEST_PASSWORD` را در محیط اجرای `tests/plugin-manager.php` تنظیم کن؛ هرگز دیتابیس مدرسه را به آزمون نده. آزمون PHP شکل پاسخ Twirp و نتیجهٔ قطع رسانه را با دادهٔ آزمایشی بررسی می‌کند. آزمون صدا، قطع نوبت و شبکهٔ VPS با نسخهٔ جدید باید روی سایت تست تکرار شود.
