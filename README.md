# bacirat-function

## کلاس مجازی برای سایت آزمایشی Baci

مبنا [شاخهٔ `arena/dbe3eaf3-baci`](https://github.com/mtagbot/Baci/tree/arena%2Fdbe3eaf3-baci)، [بستهٔ سایت `Release_V1.15` (نسخهٔ `4.221.0`)](https://github.com/mtagbot/Baci/blob/e0f3f686448642cf04ea01fcb60e79a7a786b902/Release_V1.15-Site.zip) است.

1. [به‌روزرسانی مدیر Baci ۰٫۱٫۱۲](artifacts/baci-plugin-manager-update-v0.1.12.zip) — برای نصب موجود؛ ZIP فقط `plugins/school-plugins.php` دارد و در **File Manager هاست** باز می‌شود. ابتدا با مدیر قبلی «غیرفعال‌سازی (حفظ داده)» بزن. برای نصب نخستین بار، [بستهٔ کامل پنل Baci](artifacts/baci-plugin-manager-v0.1.12.zip) و [راهنما](plugin-manager/README-fa.md) را ببین. بستهٔ قدیمی `mtagbot` را روی Baci جایگزین نکن.
2. [افزونهٔ کلاس مجازی ۰٫۴٫۶](artifacts/school-classroom-plugin-v0.4.6.zip) — پس از دیدن نسخهٔ `0.1.12` مدیر، ZIP را دست‌نخورده در **تنظیمات دیگر ← افزونه‌ها** آپلود و فعال کن. [چهار ساعت زنگ](plugin-manager/README-fa.md#bell-hours)، تنظیمات رسانه و گزارش‌های قبلی حفظ می‌شوند.
3. [آزمایش ۲۴ ساعتهٔ جمعه](plugin-manager/README-fa.md#friday-test) — در تنظیمات کلاس مجازی یک جمعهٔ میلادی مشخص را ثبت کن. از نیمه‌شب تا نیمه‌شب تهران، دبیران فعال در هر کلاسِ تعریف‌شدهٔ سال پیش‌فرض یک اتاق آزمایشی مشترک دارند. ایجاد اتاق با نخستین کلیک دبیر است. مدیر می‌تواند **ورود آزمایشی دانش‌آموزانِ همان کلاس** را جداگانه فعال کند تا انتظار و تایمر را امتحان کنند؛ بدون گزارش رسمی یا اعلان. برنامهٔ عادی عوض نمی‌شود و تست به جمعهٔ بعد منتقل نمی‌شود.
4. [وب‌هوک بومی LiveKit در VPS تست](server/WEBHOOK-fa.md) — فقط اگر گیرندهٔ فعلی تنظیم نیست. برای **دوربین** روی رسانهٔ قدیمیِ فقط‌صوت، [فعال‌کردن VP8 روی VPS اختصاصی](server/README-fa.md#camera-upgrade) یک مرحلهٔ جداست؛ صدا و تخته به این مرحله نیاز ندارند.

افزونه از نشست، پایگاه و حساب‌های همان مدرسه استفاده می‌کند. در Baci، جدول برنامهٔ هفتگی مدیریت جمعه را ثبت نمی‌کند؛ حالت آزمایشی مستقل از آن است. برای کلاس‌های رسمی، مجوز دبیر و برنامهٔ هفتگی همچنان ملاک‌اند و انتظار/وقفه در حضور حساب نمی‌شود. عنوان اتاق از نام تنظیم‌شدهٔ مدرسه و شمارهٔ پایه/کلاس (مثلاً `7/1`) می‌آید. حاضران و گفت‌وگو در موبایل هم کنار هم‌اند. در پانوشت تخته فقط شمارهٔ صفحهٔ فایل می‌آید؛ نوار گوینده‌ها فقط موقع صحبت نشان داده می‌شود. ساعت شروع کلاس زیر خروج و مدت حضور تأییدشده کنار نام دانش‌آموز است. نوشته هنگام حرکت قلم همگام می‌شود؛ حرکت‌های کوتاهِ دریافت‌شده در یک پاسخ هم تدریجی نمایش داده می‌شوند. پاک‌کن با لمس یا کشیدن روی یک خط، تمام همان حرکت قلم را برمی‌دارد. دبیر و مدیر می‌توانند در منوی سربرگ اجازهٔ میکروفون، دوربین و قلم را گروهی بدهند یا بگیرند؛ در فهرست حاضران هم دکمه‌های تکی آیکونی‌اند. دانش‌آموزان با عکس موجود مدرسه و نام خانوادگی نمایش داده می‌شوند. اجازهٔ دوربین آن را روشن نمی‌کند؛ خود فرد باید دکمهٔ دوربین را بزند. اشتراک صفحه فعال نشده است. نصب را روی کپی مستقل انجام بده؛ هیچ تغییری روی سایت یا VPS اصلی اجرا نشده است.

### ساخت و آزمون محلی

```sh
python3 scripts/build-managed-school.py --output-dir /tmp/school-classroom-build
php tests/plugin-manager.php
php tests/school-classroom.php
php tests/classroom-lessons.php
node --test tests/classroom-*.cjs
MPM_TEST_BACI=/tmp/baci-site python3 -m unittest discover -s tests -p 'test_*.py'
```

ساخت، SDK ثابت از ZIP منتشرشدهٔ قدیمی و PDF.js ثابت از npm را با هش تأیید می‌کند. برای بازسازی [مدیر قدیمی ۰٫۱٫۷ و کلاس ۰٫۴٫۱](https://github.com/Maxess/bacirat-function/tree/c63cefd97defc6f2026a63af5ed5a87fb6a919eb) از سورس همان انتشار استفاده کن. `MPM_TEST_BACI` باید به خروجی بستهٔ دست‌نخوردهٔ Baci Site V1.15 اشاره کند؛ بدون آن آزمون اعمال/برگشت وصلهٔ Baci رد می‌شود (skip). برای ساخت آفلاین از `--pdf-archive` با همان آرشیو npm استفاده کن. آزمون PHP به `pdo_sqlite` و برای چرخهٔ مدیر به `ZipArchive` و `OpenSSL` نیاز دارد. برای اجرای `tests/plugin-manager.php` و `tests/classroom-lessons.php` روی MariaDB/MySQL، `MPM_TEST_DSN` را روی **پایگاه محلی خالی و موقت** `mpm_fixture_*` تنظیم کن (نمونه: `mysql:host=127.0.0.1;port=3306;dbname=mpm_fixture_local;charset=utf8mb4`) و `MPM_TEST_USER` و `MPM_TEST_PASSWORD` را در محیط بده. پایگاه واقعی مدرسه را به آزمون نده.

آزمون‌ها زمان زنگ و جمعه، چت/تخته، حدود مجوزها، ارتقا/حذف و اعلان را با دادهٔ مصنوعی بررسی می‌کنند. ارتقای ZIPها از کلاس `0.4.5` و مدیر `0.1.11` روی Baci آزمایشی با MariaDB، حفظ گزارش‌ها و تنظیمات را تأیید کرد. در Chromium روی HTTPS، چیدمان موبایل، دسترسی‌های تکی و گروهی، عکس حاضران، نوشتن با لمس روی PDF و بازگشت به همان زنگ بررسی شد. فریم‌های دوربین آزمایشی روی اتصال مستقیم WebRTC با VP8 به مرورگر دوم رسیدند؛ سیگنال‌دهی و API سرویس LiveKit در این آزمون شبیه‌سازی شدند. صدا و تصویر روی VPS واقعی، اتصال گوشی و ظرفیت هنوز به آزمون جداگانه نیاز دارند.
