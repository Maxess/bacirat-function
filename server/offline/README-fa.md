# بستهٔ آفلاین VPS کلاس مجازی — شروع از اینجا

**این بسته فقط برای VPS اختصاصی تازه با Ubuntu 24.04 LTS (۶۴ بیتی / amd64 / x86_64) است.**
افزونه و دیتابیس مدرسه روی هاست فعلی می‌مانند. این بسته برای هاست اشتراکی، ARM، کانتینر،
یا ارتقا روی VPS قبلی نیست. حداقل ۲ گیگ RAM و ۸ گیگ فضای خالی؛ برای شروع ۲ هسته، ۴ گیگ
RAM و دیسک ۲۵ گیگ پیشنهاد می‌شود. ظرفیت کلاس واقعی را با یک آزمایش کنترل‌شده بسنج.

## قبل از اجرا: از پشتیبانی VPS یا دامنه همین‌ها را بخواه

۱. **IPv4 عمومی** VPS جدید و امکان اتصال SSH/SFTP. از تصویر رسمی Ubuntu 24.04 amd64 استفاده کن.
۲. برای نمونه `media.example.ir`، رکورد **A مستقیم** به همان IPv4. برای این زیردامنه **AAAA و Proxy/CDN** نگذار.
   اگر همان زیردامنهٔ VPS قدیمی را منتقل می‌کنی، تغییر DNS را به زمان نگهداری موکول کن؛
   می‌توانی نصب VPS تازه را پیش از تغییر DNS انجام دهی. در فایروال پنل (و اگر فایروال خود سرور روشن است، در آن هم)
   فقط **443/TCP، 7882/UDP، 7881/TCP** را برای کلاس مجاز کن. پورت SSH قبلی را عوض نکن.
   **80 لازم نیست**؛ `7880` و `7883` داخلی‌اند. نصب‌گر هیچ فایروال یا وب‌سرور موجودی را تغییر نمی‌دهد.
۳. یک **گواهی عمومی معتبر برای همان زیردامنه** و کلید خصوصی متناظر: `fullchain.pem` (همراه واسطه‌ها)
   و `privkey.pem` (PEM بدون رمز، مجوز 0600). این‌ها را از مرجع صدور یا پشتیبانی بگیر؛ با DNS-01 می‌توان
   پیش از جابه‌جایی DNS صادر کرد. گواهی سایت مدرسه را فقط اگر همین نام رسانه را پوشش می‌دهد استفاده کن.
   فایل خصوصی را ایمیل یا در چت نفرست. گواهی خودامضا، گواهی فقط CDN و خاموش‌کردن بررسی TLS جایگزین نیست.

نصب هیچ چیزی از اینترنت دانلود نمی‌کند: LiveKit، Caddy، گیرندهٔ بومی ضبط، رندرکننده، Chromium headless،
Python، FFmpeg (H.264/AAC)، کتابخانه‌ها، فونت‌ها و CAها از همین بسته‌اند. تصویر پایهٔ Ubuntu (با systemd،
APT/dpkg و ابزارهای پایه) پیش‌نیاز است، نه چیزی که نصب‌گر روی دیسک نصب کند. **استفاده از کلاس** به ارتباط
HTTPS دوطرفه بین VPS و سایت، DNS و اتصال دستگاه‌ها به رسانه نیاز دارد. ارسال اختیاری فیلم/حضور همچنان
به ربات‌ها و APIهای موجود مدرسه نیاز دارد. برای نصب اولیه سرویس Redis، Docker، CDN یا حساب ربات تازه لازم نیست.

## ۱. یک فرمان روی VPS تازه

فایل `baci-classroom-vps-offline-v1.0.0-ubuntu24.04-amd64.tar.gz` و فایل‌های TLS را با SFTP
به **پوشهٔ خانهٔ همان حساب SSH** منتقل کن. قبل از اجرا SHA-256 آرشیو را با فایل SHA256SUMS
در صفحهٔ انتشار مقایسه کن (`sha256sum نام-آرشیو`). فایل اتصال خصوصی داخل انتشار عمومی نیست.
از همان پوشهٔ خانه، این یک خط را در SSH اجرا کن:

```bash
chmod 600 privkey.pem && tar -xzf baci-classroom-vps-offline-v1.0.0-ubuntu24.04-amd64.tar.gz && sudo bash baci-classroom-vps-offline/install.sh
```

TLS را کنار آرشیو بگذار، **داخل پوشهٔ بازشدهٔ بسته نگذار**. نصب‌گر فقط سه مقدار می‌پرسد:

- نشانی **خود سایت مدرسه**، مثلاً `https://school.example.ir` یا `https://school.example.ir/baci`؛
  صفحهٔ ورود یا نشانی «تنظیمات دیگر» را وارد نکن.
- نام رسانه، مثلاً `media.example.ir`، بدون `https://`.
- IPv4 عمومی VPS جدید، همان عددی که ارائه‌دهنده داده است.

در پایان باید `installation=ok` و مسیر `Baci-VPS-pairing.json` نمایش داده شود. این فایل فقط برای
مدیر کل مدرسه است و رمزهای جداگانهٔ رسانه و ضبط را دارد. بدون وارد کردن کلید در ترمینال یا چت، آن را
با SFTP از همان VPS بگیر. اگر دوباره لازم شد: `sudo baci-vps export` (فایل موجود را بازنویسی نمی‌کند).

اگر دوست داری بدون نصب بررسی کنی، پس از بازکردن آرشیو `sudo bash baci-classroom-vps-offline/install.sh --check`
را بزن. برای نصب غیرتعاملی از `--site`، `--media`، `--ipv4` و در صورت تفاوت نام‌ها `--cert`، `--key` استفاده کن.

## ۲. یک فایل را در پنل مدرسه وارد کن

- اگر مدیر افزونه‌ها هنوز ۰٫۱٫۳۰ یا پایین‌تر است، ZIP کوچک `baci-classroom-site-pairing-v0.1.31.zip`
  را روی رایانه باز کن و راهنمای داخل آن را اجرا کن. **مدیر ۰٫۱٫۳۱ و کلاس ۰٫۴٫۲۴** لازم است؛ اگر کلاس
  ۰٫۴٫۲۴ را داری لازم نیست دوباره نصبش کنی. اول پشتیبان خصوصی سایت، دیتابیس و پوشهٔ خصوصی مدیر را بگیر.
- اگر کلاس فعال است: پس از پایان زنگ‌ها، رسید فیلم‌ها و تخلیهٔ صف اعلان، در «تنظیمات دیگر ← افزونه‌ها»
  **آماده‌سازی ارتقا (حفظ داده و کنترل صف)** را بزن. «غیرفعال‌سازی عادی» یا «حذف کامل» نزن.
- در **اتصال یک‌مرحله‌ای VPS جدید** فایل `Baci-VPS-pairing.json` را آپلود و تأیید کن؛ سپس وقتی DNS آماده است
  **فعال‌سازی** را بزن. زمان‌بندی، سقف، گزارش‌ها، گزینهٔ ضبط، اعلان‌ها و مقصد گروه‌ها عوض نمی‌شوند.
  Cron فعلی **روی هاست مدرسه** را نگه دار. نصب‌گر عمداً زنگ، ضبط یا اعلان حل‌نشده را پاک نمی‌کند.

پس از اتصال، نسخهٔ قابل‌انتقال JSON را از پوشهٔ خانه/دانلودها حذف کن یا فقط در پشتیبان رمزگذاری‌شده نگه دار.
نسخهٔ اصلی آن در `/etc/school-classroom/site-pairing.json` روی VPS با دسترسی فقط root باقی می‌ماند.

## ۳. تأیید نهایی (قبل از دعوت دانش‌آموزان)

```bash
sudo baci-vps doctor --online
```

`local=ok` یعنی HTTPS محلی با گواهی معتبر، درگاه ورود، API امضاشده و سرویس‌های ضبط بررسی شده‌اند.
`media_dns=ok` و `school_webhook=ok` را ببین. حالت `school_recorder=not_verified_or_disabled`
اگر ضبط را در سایت روشن نکرده‌ای طبیعی است؛ اگر روشن است حدود ۳۰ ثانیه صبر و دوباره بررسی کن.
از **بیرون VPS** در مرورگر `https://نام-رسانه/healthz` را باز کن. سپس با دو دستگاه و دو حساب آزمایشی
ورود، صدای رفت‌وبرگشت و پایان زنگ را امتحان کن. ۲۰۰ شدن `healthz` به تنهایی UDP/کیفیت یا ظرفیت را ثابت نمی‌کند.
اگر ضبط می‌خواهی، فقط با گروه آزمایشی دارای مجوز و تنظیمات همان سایت آزمایش کن. آزمون نصب هیچ پیامی نمی‌فرستد.

## اگر متوقف شد یا VPS قبلی از دست رفته

- **Integrity**: آرشیو را با SHA-256 انتشار مقایسه و دوباره در پوشه‌ای پاک باز کن؛ فایل داخل بسته را دستکاری نکن.
- **TLS**: نام در گواهی، `fullchain.pem`، تطابق کلید، مجوز `0600` و ساعت VPS را با پشتیبانی بررسی کن.
- **Existing path/port**: نصب‌گر چیزی را بازنویسی نمی‌کند. سرویس فعلی را حذف یا متوقف نکن؛ از یک تصویر تازه استفاده کن.
- **Offline APT**: اگر apt دیگری مشغول است بگذار تمام شود. خطای بستهٔ نگه‌داشته‌شده یا ناسازگار را با downgrade، حذف
  بستهٔ سیستم یا فعال‌کردن دانلود جبران نکن. به تصویر پشتیبانی‌شده یا بستهٔ تازه‌تر برگرد. اگر شروع کلاس شکست بخورد،
  نصب‌گر سرویس‌های اختصاصی تازه را برمی‌گرداند و پیش‌نیازهای Ubuntu را باقی می‌گذارد. در قطع برق/`kill -9` ممکن است
  برگشت کامل نشود؛ به snapshot قبل از نصب یا تصویر تازه برگرد، نه حذف دستی مسیرها.
- نصب موفقِ دوباره روی VPS موجود فقط وضعیت را می‌خواند؛ کلیدها را عوض نمی‌کند. این ابزار، داده یا ویدیوی VPS قدیمی
  را منتقل نمی‌کند. اگر سایت هنوز زنگ یا صف حل‌نشده از VPS ازکارافتاده دارد، اتصال تازه عمداً مسدود است؛
  اول از هاست و داده‌ها پشتیبان بگیر و از مدیر فنی کمک بخواه. برای برگشت، VPS قدیمی و پشتیبان سایت را تا بعد از آزمون حفظ کن.
- گواهی از داخل بسته صادر/تمدید نمی‌شود؛ تاریخش را ثبت کن و قبل از انقضا برای جایگزینی گواهی با پشتیبانی هماهنگ کن.
  بستهٔ آرشیوی به‌طور خودکار به‌روز نمی‌شود. روی VPS زنده این نصب‌گر را برای ارتقا اجرا نکن.
- برای گزارش مشکل، فقط کد پیام و مرحله را بفرست. کلید، فایل JSON، ویدیو یا لاگ خصوصی را نفرست.
